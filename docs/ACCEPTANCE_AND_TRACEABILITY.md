# EduProject — приёмка и трассировка Sprint 1

Дата подготовки: 28 октября 2026 года. Актуализация 29 октября: полные исходные AC девяти карточек подтверждены в Jira и сохранены в `eduproject_lab2_plan/jira_snapshot_2026-10-29.json`. Случаи ниже являются рабочей детализацией для согласования командой. Все случаи имеют исходный статус `pending`; фактические результаты, проверяющие, даты и версия приложения заполняются после выполнения. Наличие этого перечня не является результатом тестирования.

## Условия проверки

Используются три независимых браузерных сессии: L — тимлид, S — студент по приглашению, X — посторонний пользователь. Для назначения нужен второй активный student/lead того же проекта и недоступные кандидаты: teacher, неактивный и участник другого проекта. Дополнительные роли допустимо подготовить тестовыми фикстурами; такой API-тест не объявляется готовностью пользовательского сценария US-07/09.

Учебные данные: проект «EduProject — учебный пилот», цель «Проверить совместное планирование», ожидаемый результат «Два участника видят назначенную задачу и сохранённое состояние», задача «Реализовать приглашение участника». Даты задаются относительно фактического времени проверки и содержат UTC offset. Для граничных тестов часов используется фиксированное время тестового окружения.

Автоматические тесты OIDC используют управляемые ответы провайдера. Отдельный настоящий Telegram E2E проводится после создания бота, настройки Login и стенда. Пока это условие не выполнено, AT-01 и внешний участок AT-35 остаются pending независимо от результатов unit/integration.

## Запись фактического результата

Для выполненного случая в карточке или журнале сохраняются: `case_id`, фактические дата/время с часовым поясом, `commit_sha`, окружение, проверяющий, входные данные, ожидаемый и фактический результаты, `pass/fail/blocked`, ссылка на доказательство, связанный дефект и результат повторной проверки. В итоговой матрице нет автоматического `pass` по одному лишь наличию тестового файла. Выполнение в тестовых фикстурах и настоящем внешнем окружении отмечается раздельно.
