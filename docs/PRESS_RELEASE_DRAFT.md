# EduProject готовит учебную версию для совместного планирования студенческих проектов

Черновик от 28 октября 2026 года. Текст описывает планируемый результат и подлежит утверждению после приёмки; публичный запуск не объявлен.

Команда EduProject разрабатывает образовательную веб-платформу, которая объединит задачи, сроки и ответственность участников в общем пространстве учебного проекта. Первый программный инкремент предназначен для студентов и тимлидов, которым важно видеть актуальное состояние совместной работы.

После успешной приёмки учебная версия позволит войти через Telegram, создать проект, пригласить студентов, поставить задачу, назначить исполнителя и начать работу на общей доске. Проверка инкремента предусматривает две независимые пользовательские сессии, сохранность данных и отказ в доступе постороннему пользователю.

Команда завершила Sprint 0 проектирования и ведёт первый спринт реализации. В текущем объёме не заявляются весь MVP, доставка уведомлений, сдача и проверка результатов или интеграция с ИСУ. Эти возможности остаются направлениями дальнейшего развития.

Дату доступности, адрес учебного стенда и фактически принятые функции команда сообщит после настройки Telegram Login, сквозной проверки и решения Product Owner о выпуске.
